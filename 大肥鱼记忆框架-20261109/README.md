大肥鱼记忆框架
================================================================
一个 AI 同伴的长期记忆方案：窗口会清空，账本不会。
导出：20261109 · 纯 Python + Markdown · 零外部服务依赖

──────────────────────────────
这是什么
──────────────────────────────
不是"存个库、需要时查一下"那种记忆。它的出发点是承认一件事：

    上下文窗口必须定期清空，否则每句话都要重发全部历史。

清空之后靠什么接上？六本账：

    薄身份  每轮注入的名字/性格/目标（222 字）
    流水    刚才 6 句原话
    交接    换会话时把"聊到哪儿"压成 400 字，只活 90 分钟
    落账    抽出长期事实，带（真）/（转述）/（编）标签
    主账本  语义检索（可选，接 Mnemon）
    原文    一行一句不加工 + 每天 1~2KB 要目

──────────────────────────────
包里有什么
──────────────────────────────
engine/     记忆引擎（8 个 py + 星图 html + 配置）
  paths.py          唯一的路径来源（读 paths.json）
  configure.py      填一次路径就配好
  memory_inject.py  检索 / 注入 / 流水 / HTTP 服务（:3132）
  retention.py      记忆强度衰减 + 睡着（dormant）
  handoff.py        交接摘要
  facts.py          主动落账（带真假标注）
  daily_digest.py   要目（每天 1~2KB）
  snapshot.py       快照 / 回滚
  check.py          验收
  star.html         记忆星图
  config.json       数据源开关、注入参数
  her-core.template.md   薄身份模板

host/       宿主侧挂点
  host-hooks.js     四处钩子（归档 / 注入 / 交接 / 轮换）
  config.example.json   相关配置样例

──────────────────────────────
怎么跑
──────────────────────────────
1) 配路径
   cd engine
   python configure.py

   会在 engine/ 生成 paths.json。绝对路径**一个都不写死在代码里**，
   全从这一个文件读。

2) 放薄身份
   copy her-core.template.md <state>\her-core.md
   然后把里面的 <你的名字> / <性> / <目标> 填掉。
   跳过这步它也能跑，只是没有"我是谁"。

3) 验收
   python check.py

   第一次会报缺归档/缺块，属正常——还没有数据。

4) 起服务
   python memory_inject.py

   默认监听 127.0.0.1:3132。接口：
     GET /refresh?key=private:xxx   重算注入块
     GET /block?key=...             看块内容
     GET /digest?date=&force=1      生成要目
     GET /dormant                   看谁睡着了
     GET /wake?id=xxx               叫醒
     GET /star                      记忆星图
     GET /stats /health

5) 接宿主
   把 host/host-hooks.js 里的四个函数接进你的消息流，见文件头注释。

──────────────────────────────
路径约定
──────────────────────────────
代码里不出现任何绝对路径。全部来自 paths.json：

    engine        引擎目录（默认 "." 即自身目录）
    bridge        QQ 桥接根目录
    state         状态目录（social-v2.json / her-notes / her-core.md）
    archive       归档根目录（QQ / 归档要目 / 交接）
    mnemonDb      Mnemon 记忆库路径（可空）
    apiBase/apiKey/apiModel   压缩用的模型接口

host-hooks.js 里用占位符：
    <engine>      引擎目录
    <state>       状态目录

──────────────────────────────
它不适合什么
──────────────────────────────
· 不适合当通用中间件：会话结构、注入时机都是按单人聊天定的
· 不适合高并发：单进程 HTTP + 文件，没有队列
· 不适合非中文场景：提示词、分词、标签都是中文
· 零配置跑不起来：宿主侧四处钩子得接

──────────────────────────────
一条边界
──────────────────────────────
记忆库只放"关于人的事"。本机路径、报错栈、配置项这类维修记录不进记忆库——
它们会稀释她对自己的记忆。
